# Hema AI — Obsidian Intelligence v2

A Node.js / Express + TypeScript web application migrated from Python/Flask, featuring:

- **Hema NLP Engine**: Tokenization, contraction expansion, spell correction, intent classification, named entity recognition, and semantic search over an in-memory Q&A knowledge base.
- **Safe Math Solver**: Arithmetic expressions, factorials, number sequence prediction, linear equations, roots, and combinatorics.
- **Multi-Source Web Search**: Live synthesis from Wikipedia, DuckDuckGo Instant Answer API, and the Free Dictionary API with automatic in-memory learning.
- **Document & Image Analysis**: Code metrics, CSV previews, Markdown/text key-point extraction, and image header inspection.

## Running the App

```bash
npm install
npm run dev
```

The server listens on `http://0.0.0.0:3000`.
